# AI working rules

Before creating or changing UI components, read and follow
`DESIGN-SYSTEM.md`.

- Use semantic colour and typography roles in components.
- Use the shared spacing and radius scales.
- Do not use raw colours or primitive colour tokens in component CSS.
- Do not invent a missing token or change a shared token without human
  approval.
- Review applicable states, both themes and WCAG AA contrast.
- Run `npm run typecheck` and `npm run build-storybook` after implementation.
